# AgriRelay

AgriRelay coordinates crop planning, shared inputs and machinery, collection centers, quality lots, cold-chain pickups and cooperative settlements for small farmers.

## Stack

- Elixir and Phoenix for resilient cooperative workflows
- Phoenix LiveView for low-bandwidth operations
- PostgreSQL with PostGIS for farm and logistics geography
- Oban for durable background jobs
- Broadway with Apache Pulsar for event pipelines
- Redis, OpenTelemetry and Docker

Merge feature work by numeric branch prefix.
